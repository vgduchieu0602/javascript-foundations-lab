# JavaScript Foundations Lab

A one-day Vanilla JavaScript speed-run portfolio. **Implemented is not the same as independently verified.**

## Run

- Open `index.html` in your browser, or run `npm run serve` and visit http://localhost:8080
- Run `npm test` for automated checks.
